# 프로필 페이지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자마다 공개·비공개 프로필(활동 잔디, 통계, 쓴 글·쓴 댓글·스크랩 탭)과 프로필 수정(사진, 닉네임, 공개 설정), 글 스크랩을 추가한다.

**Architecture:** 백엔드에 `profile` 패키지(프로필 조회·수정)와 `scrap` 패키지를 새로 만들고, 기존 `user`·`image`·`post`·`comment`는 필요한 조회 메서드만 늘린다. 테이블은 Flyway `V6` 하나로 추가한다. 프론트엔드는 프로필 화면·수정 화면·스크랩 버튼·공통 `Avatar`를 추가하고, 잔디 배치는 순수 함수로 분리한다.

**Tech Stack:** 기존과 같음 — Spring Boot 4.1, Java 21, JPA, Flyway, PostgreSQL 18, Testcontainers / React 19, TypeScript, React Router, TanStack Query, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-24-profile-design.md` (기반: `docs/superpowers/specs/2026-10-24-aram-community-v1-design.md`)

## Global Constraints

- 프로젝트 규칙은 `CLAUDE.md`를 따른다(해요체 문구, 오류 형식 `{code, message, fieldErrors}`, Flyway만으로 DB 변경, 커밋 이메일 noreply, Docker Desktop을 에이전트가 켜지 않기).
- 새 오류 코드: `USER_NOT_FOUND(404, "사용자를 찾을 수 없어요")`, `PROFILE_PRIVATE(403, "비공개 프로필이에요")`.
- 활동 날짜는 한국 시간(`Asia/Seoul`). 잔디 기간 `to` = 오늘(KST), `from` = `to`가 속한 주의 일요일 − 52주(53열). 화면 폭 560px 이하면 마지막 26열.
- 잔디 색 단계: 0개 → 0, 1개 → 1, 2개 → 2, 3~4개 → 3, 5개 이상 → 4.
- 칸 설명: `"2026.10.24 · 글 1개, 댓글 2개"`, 활동 없으면 `"2026.10.24 · 활동 없음"`. 카드 제목 오른쪽 `"최근 1년 동안 N일 활동"`(53주 전체 기준).
- 날짜 표기 `YYYY.MM.DD`. 탭과 페이지는 주소 `?tab=posts|comments|scraps&page=`. 목록은 20개씩.
- 보여줄 사진 순서: 직접 올린 사진(`/api/images/{profileImageId}`) → 디스코드 사진(`avatar_url`) → 기본 원형.
- 비공개 프로필은 본인만 활동·통계·목록을 볼 수 있다(관리자 포함 타인은 잠금).
- 문구: "내 프로필이에요", "가입 2026.10.24", "프로필이 비공개로 설정되었어요", "비공개 상태예요. 다른 친구에게는 자물쇠만 보여요", "아직 쓴 글이 없어요", "아직 쓴 댓글이 없어요", "아직 스크랩한 글이 없어요", "프로필을 저장했어요", "쓸 수 없는 이미지예요", "프로필 사진은 본문에 넣을 수 없어요", "로그인하고 프로필 수정하기", "☆ 스크랩", "★ 스크랩됨".

## Review Focus

1. **한국 시간 자정 경계**: KST 23:30에 쓴 글은 그날, 다음 날 00:30에 쓴 글은 다음 날 칸에 들어가야 한다. → Task 4 테스트.
2. **디스코드 재로그인 후 직접 올린 사진 유지**: 로그인 때 디스코드 사진 주소만 갱신하고 직접 올린 사진은 그대로. → Task 1 테스트.
3. **비공개 목록을 주소로 직접 요청**: 화면에서 숨기는 것만으로 부족하다. 남(관리자 포함)이 `/api/users/{id}/posts|comments|scraps`를 부르면 403. → Task 4 테스트.
4. **프로필 사진이 사라지는 경우**: 정리 작업이 지우거나, 본문에 넣은 뒤 글 삭제로 지워지면 안 된다. → Task 3 테스트.
5. **프로필 수정에서 닉네임 중복**: 409가 와도 고른 사진과 공개 설정이 그대로 남고, 닉네임 칸 아래에만 오류가 보여야 한다. → Task 8 테스트.
