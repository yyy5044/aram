# 프로필 페이지 설계

- 작성일: 2026-10-24
- 상태: 사용자 검토 대기
- 기반: `2026-10-24-aram-community-v1-design.md` (v1 완료 상태 위에 추가)
- 목업: `.superpowers/brainstorm/1882-1792828091/content/profile-v2.html` (git 제외, 참고용)

## 1. 목적

친구마다 프로필 페이지를 둔다. 내가 쓴 글과 댓글, 저장해 둔 글을 나중에 다시 찾아가고, 친구가 어떤 활동을 했는지 볼 수 있게 한다.

**성공 기준**
- 기억나지 않는 내 글, 내가 댓글을 단 글, 스크랩한 글을 프로필에서 찾아 들어갈 수 있다.
- GitHub 잔디처럼 최근 1년 동안 활동한 날이 보인다.
- 프로필 사진, 닉네임, 공개 여부를 직접 바꿀 수 있다.

## 2. 범위

**포함**: 프로필 페이지, 활동 잔디와 통계, 쓴 글·쓴 댓글·스크랩 탭, 글 스크랩, 프로필 수정(사진, 닉네임, 공개 설정), 닉네임에서 프로필로 가는 링크, 메뉴의 "내 프로필".

**제외**: 자기소개 글, 팔로우, 스크랩 폴더, 글에 스크랩 수 표시, 알림, 탈퇴.

## 3. 화면

| 화면 | 주소 | 로그인 필요 |
|---|---|---|
| 프로필 | `/users/:userId` | 아니요 |
| 프로필 수정 | `/settings/profile` | 예 |

### 3.1 들어가는 길

- 위쪽 메뉴에서 내 이름을 누르면 나오는 메뉴에 **내 프로필**(위)과 **로그아웃**(아래)이 있다.
- 글 목록 한 줄, 글 상세 메타 줄, 댓글의 닉네임을 누르면 그 사용자의 프로필로 간다.

### 3.2 프로필

위에서 아래 순서: 머리 영역 → 활동 카드 → 탭.

**머리 영역**: 프로필 사진(원형, 72px), 닉네임, 보조 문구. 내 프로필이면 닉네임 옆에 "공개" 또는 "비공개" 표시와 오른쪽에 **프로필 수정** 버튼(`/settings/profile`로 이동). 다른 사람 프로필에는 둘 다 없다. 보조 문구는 내 프로필이면 "내 프로필이에요", 아니면 "가입 2026.10.24".

**활동 카드**
- 제목 "활동", 오른쪽에 "최근 1년 동안 N일 활동"(활동이 1개 이상인 날의 수).
- 잔디: 세로 7칸(일~토), 가로는 주 단위. 맨 오른쪽 열이 이번 주이고 오늘 이후 칸은 비워 둔다. 위쪽에 월 이름(그 달이 시작되는 열 위).
- 기간: 화면 폭이 560px보다 넓으면 53주, 560px 이하면 최근 26주. 칸은 상자 폭을 주 수로 나눈 크기의 정사각형이고 가로 스크롤이 생기지 않는다.
- 하루 값 = 그날(한국 시간) 쓴 글 수 + 댓글 수. 지금 남아 있는 글과 댓글만 센다.
- 색 단계: 0개 / 1개 / 2개 / 3~4개 / 5개 이상, 점점 진한 초록.
- 칸에 마우스를 올리면 "2026.10.24 · 글 1개, 댓글 2개", 활동이 없으면 "2026.10.24 · 활동 없음".
- 아래쪽 범례 "적음 ■■■■■ 많음".
- 잔디 아래 통계 세 칸: 가입일(2026.10.24 형식), 작성한 글(N), 작성한 댓글(N). 지금 남아 있는 것만 센다.

**탭**: "쓴 글 N", "쓴 댓글 N", "스크랩 N". 기본 탭은 쓴 글. 선택한 탭과 페이지는 주소 `?tab=posts|comments|scraps&page=`에 남는다. 각 탭 20개씩, 페이지 번호는 메인과 같은 부품.
- **쓴 글**: 메인 목록과 같은 한 줄 모양, 최신순.
- **쓴 댓글**: 댓글 내용(줄바꿈 유지, 3줄 넘으면 말줄임), 그 아래 "「글 제목」에 단 댓글 · 시간". 제목을 누르면 그 글로 간다. 최신순.
- **스크랩**: 메인 목록과 같은 한 줄 모양, 스크랩한 시간의 최신순. 스크랩한 글이 삭제되면 목록에서 사라진다.
- 비어 있으면 탭마다 "아직 쓴 글이 없어요", "아직 쓴 댓글이 없어요", "아직 스크랩한 글이 없어요".

**비공개 프로필**
- 다른 사람(관리자 포함)이 보면: 머리 영역 아래에 자물쇠 그림(🔒)과 "프로필이 비공개로 설정되었어요"만 보인다. 활동 카드와 탭은 없다.
- 본인이 보면: 모든 내용이 보이고, 머리 영역 아래에 "비공개 상태예요. 다른 친구에게는 자물쇠만 보여요" 안내가 붙는다.
- 비공개여도 글과 댓글은 게시판에서 그대로 보인다. 비공개는 프로필에서 모아 보기만 막는다.

**없는 사용자**: "사용자를 찾을 수 없어요" 화면. 닉네임을 아직 정하지 않은 사용자도 없는 사용자로 취급한다.

### 3.3 프로필 수정

위에서 아래 순서: 제목 "프로필 수정" → 프로필 사진 → 닉네임 → 공개 설정 → 취소·저장.

- **프로필 사진**: 지금 사진(원형 미리보기), **사진 바꾸기**, **디스코드 사진으로 되돌리기**. 사진 바꾸기는 파일을 고르면 바로 올리고 미리보기를 바꾼다(저장 전까지 적용되지 않는다). 형식·용량 규칙은 글 이미지와 같다(jpg, png, webp, gif, 10MB). 안내 문구 "jpg, png, webp, gif · 10MB 이하. 동그랗게 잘려서 보여요." 직접 올린 사진이 없으면 되돌리기 버튼은 비활성.
- **닉네임**: 기존 규칙(2~12자 한글·영문·숫자·밑줄, 대소문자 무시 중복 불가). 안내 문구 "2~12자 한글, 영문, 숫자, 밑줄".
- **공개 설정**: 스위치 "프로필 공개", 설명 "끄면 다른 친구에게는 자물쇠와 안내 문구만 보여요. 글과 댓글은 게시판에서 그대로 보여요." 기본은 켜짐.
- **저장**: 세 값을 한 번에 저장하고 내 프로필로 이동, 알림 "프로필을 저장했어요". 오류는 해당 칸 아래에 보여준다.
- **취소**: 저장하지 않고 내 프로필로 돌아간다.
- 로그인 전에는 "로그인하고 프로필 수정하기" 버튼을 보여준다.

### 3.4 글 상세의 스크랩 버튼

- 추천 버튼 오른쪽에 "☆ 스크랩". 스크랩한 상태면 "★ 스크랩됨"(파란색 채움).
- 누르면 바로 바뀌고, 실패하면 되돌아가며 알림을 띄운다(추천 버튼과 같은 방식).
- 로그인 전에 누르면 알림 "로그인이 필요해요".
- 글에 스크랩 수는 표시하지 않는다.

### 3.5 프로필 사진이 쓰이는 곳

머리 메뉴, 글 상세 글쓴이, 댓글, 프로필 머리 영역. 보여줄 사진은 **직접 올린 사진 → 디스코드 사진 → 기본 원형** 순서로 고른다. 디스코드로 다시 로그인해도 직접 올린 사진은 바뀌지 않는다(디스코드 사진 주소만 갱신된다).

## 5. 데이터

`V6__profile_and_scraps.sql` 하나로 추가한다.

### users 추가 컬럼
| 컬럼 | 타입 | 비고 |
|---|---|---|
| profile_image_id | uuid null, FK images(id) on delete set null | 직접 올린 프로필 사진 |
| profile_public | boolean not null default true | |

`avatar_url`(디스코드 사진)은 그대로 두고 로그인 때마다 갱신한다.

### scraps
| 컬럼 | 타입 | 비고 |
|---|---|---|
| user_id | bigint FK users not null | |
| post_id | bigint FK posts not null, on delete cascade | |
| created_at | timestamptz not null | |

PK `(user_id, post_id)`, 인덱스 `(user_id, created_at desc)`.

### 활동 계산용 인덱스
`posts (author_id, created_at)`, `comments (author_id, created_at)`.

### 이미지 정리 작업 변경
"글에 연결되지 않고 24시간 지난 이미지"에서 **어떤 사용자의 `profile_image_id`로 쓰이는 이미지는 제외**한다. 프로필 사진을 바꾸면 이전 사진은 아무 데도 쓰이지 않게 되어, 24시간 뒤 정리 작업이 지운다.

### 글 본문 이미지 규칙 추가
프로필 사진으로 쓰이는 이미지는 글 본문에 넣을 수 없다(400 `fieldErrors.content` "프로필 사진은 본문에 넣을 수 없어요"). 글을 지울 때 프로필 사진이 함께 지워지는 일을 막는다.

## 6. API

| 메서드 | 주소 | 설명 | 권한 |
|---|---|---|---|
| GET | `/api/users/{id}/profile` | 프로필 머리, 통계, 활동 | 누구나 |
| GET | `/api/users/{id}/posts?page=` | 쓴 글 (`PageResponse<PostListItem>`) | 누구나, 비공개면 본인만 |
| GET | `/api/users/{id}/comments?page=` | 쓴 댓글 | 누구나, 비공개면 본인만 |
| GET | `/api/users/{id}/scraps?page=` | 스크랩 (`PageResponse<PostListItem>`) | 누구나, 비공개면 본인만 |
| PUT | `/api/me/profile` | 프로필 수정 | 로그인 |
| PUT | `/api/posts/{id}/scrap` | 스크랩 | 로그인 |
| DELETE | `/api/posts/{id}/scrap` | 스크랩 취소 | 로그인 |

- `GET /api/users/{id}/profile` 응답: `{ id, nickname, avatarUrl, joinedAt, profilePublic, mine, locked, stats, activity }`.
  - `locked` = 비공개이고 본인이 아님. `locked`이면 `stats`, `activity`는 `null`.
  - `stats`: `{ postCount, commentCount, scrapCount }` (탭 숫자에도 쓴다).
  - `activity`: `{ from, to, days: [{ date, posts, comments }] }`. `to`는 오늘(한국 시간), `from`은 `to`가 속한 주의 일요일에서 52주 전 일요일. `days`에는 활동이 있는 날만 넣는다. 날짜는 `YYYY-MM-DD`.
- 비공개 목록 요청(본인 아님): 403 `PROFILE_PRIVATE` "비공개 프로필이에요".
- 없는 사용자 또는 닉네임 미설정 사용자: 404 `USER_NOT_FOUND` "사용자를 찾을 수 없어요".
- 쓴 댓글 항목: `{ id, content, createdAt, post: { id, title } }`.
- `PUT /api/me/profile` 요청: `{ nickname, profileImageId, profilePublic }`. `profileImageId`가 `null`이면 디스코드 사진을 쓴다. 이미지는 존재하고, 요청한 사용자가 올렸고, 글에 쓰이지 않은 것이어야 한다(아니면 400 `fieldErrors.profileImageId` "쓸 수 없는 이미지예요"). 닉네임 규칙과 메시지는 기존과 같다. 응답은 `/api/me`와 같은 형식.
- 스크랩 PUT/DELETE는 멱등이고 `{ scrappedByMe }`를 돌려준다. 없는 글은 404 `POST_NOT_FOUND`. 닉네임이 있어야 한다.
- 기존 응답 변경:
  - `/api/me`에 `profilePublic`, `profileImageId`(직접 올린 사진이 없으면 `null`) 추가. `avatarUrl`은 3.5의 순서로 고른 사진.
  - 글 상세에 `scrappedByMe` 추가.
  - 글·댓글의 `author.avatarUrl`도 3.5의 순서로 고른 사진.

## 8. 테스트

- **백엔드**: 프로필 응답(공개/비공개/본인/관리자/없는 사용자/닉네임 미설정), 통계 숫자, 활동 날짜 경계(한국 시간 자정 전후의 글이 다른 날로 잡히는지), 목록 세 가지의 정렬·페이지·잠금, 스크랩 멱등과 동시 요청, 글 삭제 시 스크랩 정리, 프로필 수정 검증(남의 이미지, 글에 쓰인 이미지, 닉네임 규칙), 디스코드 재로그인 후에도 직접 올린 사진 유지, 이미지 정리 작업이 프로필 사진을 지우지 않음.
- **프론트엔드**: 잔디 배치 함수(53주·26주, 색 단계, 칸 설명 문구), 프로필 화면(본인/남/잠금/없는 사용자, 탭 주소 반영), 프로필 수정(사진 올리기·되돌리기, 오류 표시, 저장 후 이동), 스크랩 버튼(토글, 실패 시 되돌리기, 로그인 안내), 닉네임 링크.
- **완료 확인**: 브라우저로 두 사용자 시나리오(공개 → 비공개 전환, 스크랩, 사진 변경)를 확인한다.
