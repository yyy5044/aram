# 증강·챔피언 탭 설계

- 작성일: 2026-10-24
- 상태: 사용자 검토 대기
- 기반: `2026-10-24-aram-community-v1-design.md`, `2026-10-24-profile-design.md` (두 기능이 완료된 상태 위에 추가)
- 목업: `.superpowers/brainstorm/1882-1792828091/content/tags-browse-dropdown.html` (git 제외, 참고용)

## 1. 목적

지금은 메인의 전체 글 목록만 있어서, 특정 증강이나 챔피언 이야기를 찾으려면 글에 붙은 태그를 우연히 눌러야 한다. 위쪽 메뉴에 **증강**과 **챔피언** 탭을 두어 전체 증강과 전체 챔피언을 한눈에 보고, 하나를 눌러 그 태그가 붙은 글을 바로 보게 한다.

**성공 기준**
- 증강 탭에서 프리즘·골드·실버 묶음을 펼쳐 증강을 고르면, 화면이 바뀌지 않고 그 아래로 해당 글 목록이 펼쳐진다.
- 챔피언 탭에서 챔피언을 고르면 그 챔피언 글과 "자주 함께 쓰는 증강"이 펼쳐진다.
- 이름 검색과 "가나다순 / 글 많은 순" 정렬로 원하는 것을 빨리 찾는다.
- 글을 읽고 뒤로 가면 펼쳐 두었던 그 자리로 돌아온다.

## 2. 범위

**포함**: 위쪽 메뉴 탭(전체 글·증강·챔피언), 증강 목록(등급 묶음, 검색, 정렬, 글 수), 챔피언 목록(검색, 정렬, 글 수), 아래로 펼쳐지는 글 목록(정렬, 더 보기), 챔피언의 자주 함께 쓰는 증강, 증강 등급 데이터 수집.

**제외**: 지금 게임에 없는 증강을 목록에 보여주기, 패치별 글 수, 증강 설명(툴팁) 보기, 전체 글 화면 변경, 기존 태그 페이지(`/augments/:id`, `/champions/:id`) 변경.

## 3. 화면

| 화면 | 주소 | 로그인 필요 |
|---|---|---|
| 전체 글 | `/` | 아니요 (지금 그대로) |
| 증강 목록 | `/augments`, 펼친 상태는 `/augments?open=<증강 id>` | 아니요 |
| 챔피언 목록 | `/champions`, 펼친 상태는 `/champions?open=<챔피언 id>` | 아니요 |

기존 태그 페이지 `/augments/:augmentId`, `/champions/:championId`는 그대로 둔다. 글에 붙은 태그 칩은 계속 그쪽으로 간다.

### 3.1 위쪽 메뉴

- 로고 오른쪽에 **전체 글 · 증강 · 챔피언** 탭을 둔다. 지금 있는 곳의 탭은 진하게 표시한다.
  - 전체 글: 주소가 정확히 `/`일 때.
  - 증강: 주소가 `/augments`로 시작할 때(기존 태그 페이지 포함).
  - 챔피언: 주소가 `/champions`로 시작할 때(기존 태그 페이지 포함).
- 폭이 좁은 화면(480px 미만)에서는 탭 줄이 로고·글쓰기 줄 아래로 내려간다. 가로로 넘치지 않는다.

### 3.2 공통: 검색과 정렬

- 맨 위에 이름 검색칸과 **가나다순 / 글 많은 순** 버튼이 있다. 처음에는 가나다순.
- 검색은 한국어 이름에 검색어가 들어 있으면 맞는 것으로 본다. 띄어쓰기는 무시한다("하체운동"은 "하체 운동의 날"과 맞는다). 영문은 대소문자를 무시한다.
- 글 많은 순은 글 수가 많은 것부터, 같으면 가나다순.
- 검색 결과가 하나도 없으면 "검색 결과가 없어요".
- 검색어와 정렬은 주소에 남기지 않는다. 화면을 떠나면 초기화된다.

### 3.3 증강 목록

- 지금 게임에 있는(`active`) 증강만 보여준다.
- 증강은 **프리즘 → 골드 → 실버** 순서의 묶음으로 나뉜다. 처음에는 모두 접혀 있다.
- 묶음 제목 줄: 색 표시, 묶음 이름, "증강 n개 · 글 n개". 누르면 펼치고, 다시 누르면 접는다.
- 묶음 안에는 증강 칸이 격자로 놓인다. 칸마다 아이콘, 이름, "글 n개"(0개는 흐리게).
- 검색어가 있으면 맞는 증강이 있는 묶음만 보이고 모두 펼쳐진다. 제목 줄의 개수는 "증강 m/n개"가 된다.
- 주소에 `?open=`으로 펼친 증강이 있으면, 그 증강이 들어 있는 묶음은 항상 펼친다.

### 3.4 챔피언 목록

- 모든 챔피언을 묶음 없이 하나의 격자로 보여준다. 칸마다 둥근 초상화, 이름, "글 n개".

### 3.5 아래로 펼쳐지는 글 목록

- 칸을 누르면 그 칸이 강조되고, **그 칸이 있는 줄 바로 아래**에 줄 전체 폭의 펼침 영역이 생긴다. 강조된 칸에서 펼침 영역을 가리키는 작은 화살표가 있다.
- 같은 칸을 다시 누르거나 펼침 영역의 ✕를 누르면 접힌다.
- 한 번에 하나만 펼쳐진다. 다른 칸을 누르면 그쪽으로 옮겨간다.
- 펼침 상태는 주소의 `?open=<id>`로 남는다. 열고 닫을 때마다 방문 기록을 새로 쌓지 않고 바꿔 끼운다(뒤로 가기를 눌렀을 때 열고 닫은 횟수만큼 되돌아가지 않게).
- `?open=` 값이 목록에 없는 id(게임에서 빠진 증강, 잘못된 값)면 아무것도 펼치지 않는다.
- 검색으로 펼친 칸이 목록에서 사라지면 펼침 영역도 사라진다. 검색어를 지워 다시 보이면 다시 펼쳐진다.

**펼침 영역 내용** (위에서 아래 순서)
1. 제목 줄: 이름, 보조 문구(증강은 "프리즘 증강 · 게시글 n개", 챔피언은 "게시글 n개"), 글이 있으면 **최신순 / 추천순** 버튼(처음엔 최신순), 오른쪽 끝에 ✕.
2. 챔피언만: "자주 함께 쓰는 증강" 칩 줄. 그 챔피언이 태그된 글에 함께 태그된 증강을 많이 쓰인 순서로 5개까지, 칩마다 아이콘·이름·횟수. 칩을 누르면 `/augments?open=<증강 id>`로 간다. 함께 쓴 증강이 없으면 줄 자체를 보여주지 않는다.
3. 글 목록: 메인 목록과 같은 한 줄 모양(`PostListItem`). 처음 5개, 아래에 **더 보기 (n개 남음)** 버튼으로 5개씩 이어 붙인다. 남은 글이 없으면 버튼이 없다. 정렬을 바꾸면 처음 5개부터 다시.
4. 글이 없으면 "아직 이 태그가 붙은 글이 없어요".

글 제목을 누르면 글 상세로 간다. 뒤로 가면 같은 탭, 같은 펼침 상태로 돌아온다(더 보기로 불러온 양과 정렬은 처음 상태로 돌아가도 된다).

### 3.6 불러오는 중과 오류

- 목록(챔피언 또는 증강 목록과 글 수)을 불러오는 동안은 빈 화면 대신 "불러오는 중이에요".
- 둘 중 하나라도 실패하면 "잠시 후 다시 시도해주세요". 서버 오류 메시지가 있으면 그 문장을 보여준다.
- 펼침 영역의 글 목록이나 자주 함께 쓰는 증강이 실패하면 펼침 영역 안에만 같은 오류 문구를 보여준다.

## 4. 권한

새 화면과 새 API는 모두 읽기 전용이고 로그인 없이 볼 수 있다. 쓰기 API는 추가하지 않는다.

## 5. 데이터

### 증강 등급 (`V7__augment_rarity.sql`)

```sql
alter table augments add column rarity varchar(10) not null default 'SILVER';
update game_data_state set current_ddragon_version = null;
```

- 값은 `PRISMATIC`, `GOLD`, `SILVER`. 엔티티에서는 `AugmentRarity` 열거형(`@Enumerated(STRING)`).
- 두 번째 줄은 다음 동기화(서버 시작 시 한 번 돈다)가 패치가 바뀐 것처럼 전체를 다시 받게 해서, 기존 증강의 등급을 채운다.

### 게임 데이터 수집 변경 (`GameDataClient.fetchAugments`)

- `kiwi.bin.json`의 각 `AugmentData`에서 `rarity` 값을 읽는다: 값이 없거나 0이면 `SILVER`, 1이면 `GOLD`, 2면 `PRISMATIC`. 그 밖의 값은 `SILVER`로 두고 경고 로그를 남긴다.
  - 2026-10-24 기준 실제 데이터: 증강 249개 중 값 없음 71, 1이 104, 2가 74. `ARAM_GiantSlayer`, `FinalForm`, `KingMe`가 2(프리즘), `Sonata`, `ARAM_Recursion`이 1(골드), `ARAM_LegDay`, `VeilOfWarding`이 값 없음(실버).
- `Enabled`가 `false`인 증강은 받지 않는다(9개). 이미 저장돼 있던 것은 기존 규칙대로 `active = false`가 된다.
- `Augment.refresh`와 생성자가 등급을 함께 받는다.

### 글 수 계산

새 테이블은 없다. `post_champions`, `post_augments`를 태그 id로 묶어 센다(이미 태그 id 인덱스가 있다).

## 6. API

**변경: `GET /api/augments`** — 각 항목에 `rarity`(`"PRISMATIC" | "GOLD" | "SILVER"`)를 더한다. 기존 필드는 그대로.

**변경: `GET /api/posts`** — `size` 매개변수를 더한다. 1~20, 기본 20. 범위를 벗어나면 400 `INVALID_INPUT`, `fieldErrors.size = "한 번에 1~20개까지 볼 수 있어요"`. 다른 매개변수와 응답은 그대로.

**새로: `GET /api/tag-counts`**

```json
{ "champions": { "Amumu": 7, "Jinx": 5 }, "augments": { "ARAM_LegDay": 3 } }
```

- 태그별 글 수. 글이 1개 이상인 태그만 들어 있다(없으면 화면에서 0으로 본다).
- 증강은 `active`가 아닌 것도 센다(화면에서 쓰지 않을 뿐).

**새로: `GET /api/champions/{championId}/top-augments`**

```json
[ { "augment": { "id": "ARAM_LegDay", "nameKo": "하체 운동의 날", "iconUrl": "...", "active": true, "rarity": "SILVER" }, "postCount": 3 } ]
```

- 그 챔피언이 태그된 글에 함께 태그된 증강을 글 수 많은 순, 같으면 이름 가나다순으로 최대 5개.
- 지금 게임에 있는(`active`) 증강만 센다. 칩을 눌렀을 때 증강 탭에서 펼칠 수 있어야 하기 때문.
- 없는 챔피언이면 404 `CHAMPION_NOT_FOUND`, 메시지 "챔피언을 찾을 수 없어요".

## 7. 화면 구성 요소

| 파일 | 역할 |
|---|---|
| `components/Header.tsx` | 탭 세 개 추가(`NavLink`), 좁은 화면 줄바꿈 |
| `pages/AugmentsPage.tsx` | 증강 목록: 등급 묶음, 묶음 접기/펼치기 |
| `pages/ChampionsPage.tsx` | 챔피언 목록 |
| `components/tags/TagToolbar.tsx` | 검색칸과 가나다순/글 많은 순 버튼 |
| `components/tags/TagGrid.tsx` | 칸 격자와 펼침 영역 끼워 넣기(같은 줄 판단) |
| `components/tags/TagPostsPanel.tsx` | 펼침 영역: 제목 줄, 정렬, 글 5개씩 더 보기, 빈 상태, 챔피언이면 `TopAugments` |
| `components/tags/TopAugments.tsx` | 자주 함께 쓰는 증강 칩 줄 |
| `lib/tagSearch.ts` | 검색 맞춤(띄어쓰기·대소문자 무시)과 정렬 함수 |
| `api/gamedata.ts` | `useTagCounts`, `useTopAugments` 추가, `Augment` 타입에 `rarity` |
| `api/posts.ts` | `useTagPosts`(무한 쿼리, `size=5`) 추가 |

**같은 줄 판단**: `TagGrid`는 칸들을 그린 뒤 펼친 칸과 `offsetTop`이 같은 마지막 칸을 찾아 그 뒤에 펼침 영역을 넣는다(CSS grid의 한 줄 전체를 차지). 창 크기가 바뀌면 다시 계산한다. 테스트 환경(jsdom)처럼 위치 정보가 없으면 모든 칸이 한 줄로 판단되어 격자 끝에 들어간다.

**접근성**: 칸과 묶음 제목은 버튼이고 `aria-expanded`로 열림 상태를 알린다. 펼침 영역은 `role="region"`과 이름(`aria-label`, 예: "무한 궁극기 게시글").

## 8. 테스트

**서버**
- 증강 수집: `rarity` 없음/1/2/알 수 없는 값 → SILVER/GOLD/PRISMATIC/SILVER, `Enabled: false`는 빠진다.
- 동기화: 등급이 저장되고, 다음 동기화에서 등급이 바뀌면 갱신된다. `Enabled: false`가 된 기존 증강은 비활성.
- 마이그레이션 뒤 상태의 패치 값이 비어 있어 전체 동기화가 일어난다.
- `GET /api/augments`에 `rarity`가 있다.
- `GET /api/tag-counts`: 글 여러 개와 태그로 정확한 개수, 글이 없는 태그는 빠짐, 글을 지우면 줄어듦.
- `GET /api/champions/{id}/top-augments`: 순서(글 수, 같으면 이름), 최대 5개, 비활성 증강 제외, 함께 쓴 증강 없으면 빈 배열, 없는 챔피언 404.
- `GET /api/posts?size=5`: 5개씩 잘림, `size=0`과 `size=21`은 400.

**화면**
- 메뉴: 주소별로 진하게 표시되는 탭(`/`, `/augments`, `/augments/X`, `/champions`).
- 증강 목록: 처음엔 모두 접힘, 제목 누르면 펼침/접힘, 묶음 순서 프리즘→골드→실버, 비활성 증강 없음, 글 수 표시.
- 검색: 띄어쓰기 무시 맞춤, 맞는 묶음만 펼쳐짐, 결과 없음 문구.
- 정렬: 글 많은 순과 동점 가나다순.
- 칸 누르기: `?open=` 주소 반영, 펼침 영역 표시, 다시 누르면 닫힘, 다른 칸 누르면 이동, ✕로 닫힘.
- `?open=X`로 들어오면 X가 든 묶음이 펼쳐지고 펼침 영역이 보인다. 없는 id면 아무것도 안 펼침.
- 펼침 영역: 5개 표시, 더 보기로 이어 붙임(요청에 `page=2&size=5`), 남은 개수 문구, 정렬 바꾸면 처음부터, 글 없을 때 문구.
- 챔피언 펼침: 자주 함께 쓰는 증강 칩, 칩 누르면 `/augments?open=` 이동, 칩이 없으면 줄 없음.
- 오류: 목록 실패 시 문구, 펼침 영역 실패 시 영역 안 문구.
- 브라우저 확인: 실제 데이터로 증강 탭 묶음이 채워지는지, 좁은 화면에서 메뉴와 격자가 넘치지 않는지, 펼침 영역이 칸이 있는 줄 바로 아래에 들어가는지.
