# 본문 속 챔피언·증강 태그(@) 설계

- 작성일: 2026-10-26
- 상태: 사용자가 대화에서 설계를 승인함(목업 포함). 이 문서는 검토 대기.

## 1. 목적

글에서 챔피언·증강 이름이 일반 글자로만 있으면 눈에 잘 띄지 않는다. 글을 쓰다 `@`로 챔피언·증강을 불러와 **아이콘 + 굵은 이름이 담긴 작은 박스**로 문장 사이에 넣어서 읽기 쉽게 한다. 증강 박스는 마우스를 올리면(휴대폰은 누르면) 그 증강의 카드가 떠서, 설명을 찾아보러 가지 않아도 된다.

**성공 기준**
1. 글쓰기에서 `@`를 치면 챔피언·증강 후보가 함께 뜬다. 띄어쓰기 무시·초성 검색(`@ㅅㅉㅇ`)이 된다. 고르면 친 글자(`@ㅅㅉ`)가 지워지고 박스가 들어간다.
2. 고른 챔피언·증강은 글의 챔피언·증강 태그 칸에 자동으로 추가된다(한도 안에서).
3. 글 보기에서 박스는 아이콘 + 굵은 이름으로 문장 사이에 자연스럽게 보인다. 증강 박스는 PC에서 마우스를 올리면, 휴대폰에서 누르면 증강 카드가 뜨고, 벗어나거나 바깥을 누르면 닫힌다.
4. 박스를 누르거나 올려도 다른 화면으로 이동하지 않는다(사용자 결정).
5. 화면을 조작해도 없는 챔피언·증강을 박스로 저장할 수 없다.

## 2. 범위

**포함**: 본문 인라인 노드 `tagMention`(서버·화면 규칙), `@` 후보 메뉴, 태그 칸 자동 추가, 글 보기 박스, 증강 카드 띄우기(마우스·누르기), 저장 검사, 박스 이름의 본문 글자 포함.

**제외**: 박스를 눌러 모아보기로 이동(사용자가 원하지 않음), 챔피언 박스의 카드, 댓글 속 `@`, 사람(사용자) 멘션·알림, 이미 쓴 글의 일반 글자를 박스로 바꾸기.

## 3. 화면

### 3.1 `@` 후보 메뉴 (글쓰기)

- 줄 맨 앞이나 띄어쓰기 뒤에서 `@`를 치면 커서 아래에 후보 메뉴가 뜬다(`/` 메뉴와 같은 `@tiptap/suggestion`). 띄어쓰기는 검색어에 포함한다(`@거석상의 용`도 된다). 다만 맞는 후보가 없으면 메뉴가 닫힌다.
- 후보: 챔피언 전체 + **사용 중인(active) 증강**. 검색은 `lib/tagSearch.ts`의 `matchesName`(띄어쓰기·대소문자 무시, 초성·섞어 쓰기). `@`만 쳤을 때는 아무것도 보여주지 않고 "챔피언이나 증강 이름을 쳐 주세요" 한 줄만 보인다.
- 정렬: 이름이 검색어로 **시작하는** 것 먼저, 그다음 가나다순. 최대 8개.
- 한 줄: 아이콘(챔피언 둥근 20px, 증강 네모 20px + 등급 색 테두리) + 이름(15px) + 오른쪽에 "챔피언"/"증강"(13px ink-3). 높이 40, 고른 줄 `bg-ice`. 메뉴 모양은 `/` 메뉴와 같다(surface, `border-line`, `shadow-pop`, 너비 240).
- 위·아래로 고르고 Enter(또는 누르기)로 넣는다. Esc는 메뉴만 닫는다.

### 3.2 박스 넣기와 태그 칸

- 고르면 `@`+검색어를 지우고 그 자리에 박스를 넣은 뒤 띄어쓰기 한 칸을 붙인다(이어서 쓰기 쉽게).
- 박스는 한 덩어리(원자 노드)다. 백스페이스 한 번에 통째로 지워진다.
- 고른 챔피언·증강을 글의 태그 칸에 자동으로 더한다.
  - 이미 있으면 그대로 둔다.
  - 한도(챔피언 5·증강 10)가 차 있으면 본문에만 넣고 알림 "태그 칸이 가득 차서 본문에만 넣었어요".
  - 본문에서 박스를 지워도 태그는 빼지 않는다(태그 칸은 사용자가 직접 관리).
- 한 글에 박스는 30개까지. 넘으면 메뉴에서 고를 때 알림 "본문 태그는 한 글에 30개까지 넣을 수 있어요"(넣지 않음).

### 3.3 박스 모양 (편집기·글 보기 같음)

- 인라인 박스: 높이 26, 왼쪽 여백 2·오른쪽 8, 간격 5, 테두리 1px, 모서리 4(작은 표시), 세로 가운데 정렬.
- 챔피언: 둥근 초상화 20px, 바탕 `ice`, 테두리 `line-soft`.
- 증강: 네모 아이콘 20px(`AugmentIcon`, 흰 아이콘이면 등급 색을 입힘), 테두리와 옅은 바탕은 등급 색(실버 `silver`, 골드 `gold-rarity`, 프리즘 `prismatic`).
- 이름은 굵게 15px `ink`.
- 아이콘·등급은 지금 챔피언·증강 목록(이미 받아 둔 `useChampions`/`useAugments`)에서 찾는다. 목록에 없으면(옛 증강이 지워짐 등) 아이콘 없이 저장된 이름만 보인다.

### 3.4 증강 카드 띄우기 (글 보기·편집기)

- PC(마우스): 증강 박스에 마우스를 0.2초 올리면 카드가 박스 아래(공간이 없으면 위)에 뜬다. 박스와 카드 밖으로 마우스가 나가면 닫힌다.
- 휴대폰(터치): 박스를 누르면 카드가 뜨고, 바깥을 누르거나 다시 누르면 닫힌다.
- 카드: 증강 탭의 `AugmentCard`를 그대로 쓰고, 머리말 언어 설정(`lib/language.ts`)의 언어로 **한 장**만 보여준다. 내용은 `GET /api/augments/{id}?lang=`(`useAugmentDetail`, 받은 것은 캐시)로 받는다. 받는 중에는 카드 자리에 "불러오는 중…", 실패하면 "증강 정보를 불러오지 못했어요".
- 카드는 화면 밖으로 넘치지 않게 위치를 맞춘다(`@floating-ui/dom`, `@tiptap/suggestion`이 이미 쓰는 것).
- 키보드: 박스에 Tab으로 갈 수 있고(글 보기), 초점이 가면 카드가 뜨고 Esc로 닫힌다. 박스는 `role="button"`, `aria-label="{이름} 증강 카드 보기"`, `aria-expanded`.
- 챔피언 박스는 아무 동작이 없다.

## 4. 본문 규칙과 서버

### 4.1 노드

```json
{ "type": "tagMention", "attrs": { "kind": "champion", "id": "XinZhao", "label": "신짜오" } }
```

- 인라인 원자 노드. `kind`는 `champion` 또는 `augment`, `id`는 `^[A-Za-z0-9_]{1,40}$`, `label`은 1~50자. 자식·마크 없음(굵게는 박스 모양이 정한다).
- 서버 `PostContentValidator`, 화면 `editor/extensions.ts`, `editor/extensions.test.ts`를 함께 바꾼다(CLAUDE.md 규칙).
- 검사: 형식이 틀리면 "지원하지 않는 본문 형식이에요". 박스 30개 초과는 "본문 태그는 한 글에 30개까지 넣을 수 있어요".
- `label`은 본문 글자(`plainText`)에 들어간다. 그래서 박스만 있는 글도 글자가 있는 글이고, 글자 수 한도에도 포함된다.
- `ValidatedContent`에 `mentions`(종류·번호 목록, 중복 없이)를 더한다.

### 4.2 저장 검사

- `PostService`가 저장 전에 `mentions`의 챔피언·증강이 실제로 있는지 확인한다(`ChampionRepository`/`AugmentRepository`의 `findAllById`). 하나라도 없으면 400 `INVALID_INPUT`, `content` 칸에 "없는 챔피언·증강이 들어 있어요". 사용 중이 아닌(옛) 증강도 있는 것으로 친다(태그 칸과 같은 규칙).
- 태그 자동 추가는 화면이 한다. 서버는 본문 박스와 태그 칸을 따로 검사한다(박스가 태그 칸에 꼭 있어야 하는 건 아니다).

## 5. 화면 구현 메모

- `editor/TagMentionNode.ts`(인라인 원자 노드, `group: 'inline'`, `inline: true`, `atom: true`, `selectable: false`) + React NodeView `TagMentionView.tsx`.
- `editor/MentionCommand.ts`: `@tiptap/suggestion`(`char: '@'`, `allowSpaces: true`, `allowedPrefixes: [' ']`), 후보 계산은 `lib/mentionCandidates.ts`(순수 함수: 챔피언·증강 목록 + 검색어 → 정렬된 후보 8개). 메뉴 컴포넌트 `MentionMenu.tsx`.
- 편집기는 챔피언·증강 목록을 알아야 한다: `PostEditor`가 `useChampions`/`useAugments`를 받아 확장에 넘기고(편집기 저장소), 고른 결과를 `onMention(kind, id)` 콜백으로 부모(`WritePage`)에 알린다. `WritePage`가 태그 칸 상태에 더하고, 한도면 알림.
- 글 보기 `PostContentView`도 같은 NodeView로 그린다(`postExtensions()`에 노드 포함). 카드 띄우기는 `components/augment/AugmentHoverCard.tsx`.
- `/` 메뉴와 `@` 메뉴는 플러그인 키를 따로 쓴다.

## 6. 테스트

**서버**
- 검사기: `tagMention` 통과(`mentions`에 들어감, `plainText`에 label 포함), 종류·번호·이름 형식이 틀리면 거절, 31개 거절, 박스만 있는 본문 통과.
- 저장: 있는 챔피언·증강 박스로 저장 성공, 없는 번호면 "없는 챔피언·증강이 들어 있어요", 옛(비활성) 증강은 통과.

**화면**
- `mentionCandidates`: 초성·띄어쓰기 무시, 시작 일치 우선 정렬, 8개 제한, 비활성 증강 제외, 빈 검색어는 후보 없음.
- `@` 메뉴: `@ㅅㅉ` → 신짜오 후보, Enter → 박스 들어감·`@ㅅㅉ` 사라짐·뒤에 띄어쓰기, Esc 닫힘, 맞는 게 없으면 메뉴 닫힘.
- 태그 자동 추가: 고르면 `onMention` 호출, `WritePage`가 태그 칸에 추가, 한도 차면 알림·추가 안 함, 이미 있으면 그대로.
- 박스: 챔피언은 둥근 초상화·굵은 이름, 증강은 등급 테두리, 목록에 없으면 이름만.
- 카드: 마우스 올림 → 카드(선택 언어), 벗어남 → 닫힘, 누르기 → 열림/닫힘, Esc 닫힘, 받는 중·실패 문구.
- `extensions.test.ts`에 `tagMention` 추가.

**브라우저**: 글쓰기에서 `@`로 챔피언·증강을 넣고 태그 칸에 들어가는지, 등록 뒤 글 보기에서 박스 모양·증강 카드(PC 마우스, 휴대폰 크기 누르기)를 확인한다.

## 7. 주의

- 증강 카드 내용은 처음 띄울 때 한 번 받는다(이후 캐시). 글에 증강 박스가 많아도 마우스를 올린 것만 받는다.
- 박스 이름은 쓴 때의 이름이라, 나중에 게임에서 이름이 바뀌면 박스는 옛 이름, 카드는 새 이름일 수 있다. 친구 규모에서 받아들인다.
